Academic Project Abstract

Modern email-borne cyber attacks increasingly exploit distributed, multi-modal attack surfaces—combining social engineering text, domain impersonation, and concealed image steganography. Conventional defense solutions analyze these modalities in technical silos, offering binary safe/unsafe verdicts with minimal explanatory guidance for the recipient. This project presents MailSentra, an integrated, multi-modal email security platform that unites three independent detection and defense engines into a cohesive client-integrated pipeline.

The system orchestrates: (1) a four-stage email threat engine utilizing fine-tuned transformer models (DistilBERT), real-time DNS/reputation filtering, and stylometric AI text profiling; (2) a convolutional deep learning engine (EfficientNet-B2) performing image steganalysis with explainable Grad-CAM heatmaps; and (3) a declarative, policy-driven defense and awareness engine mapping heterogeneous evidence into five graded operational postures. Evaluated across eight live end-to-end scenarios, the platform demonstrates sub-2-second end-to-end multi-modal triage, zero fail-open occurrences under worker faults, and transparent, evidence-grounded awareness guidance rendered natively inside Mozilla Thunderbird and an integrated SOC dashboard.

Academic Research Core

Domain Background, Methodology & Architecture

Comprehensive technical details on the cyber threat landscape, formal problem definition, system architecture, and empirical evaluation results.

The Modern Multi-Vector Email Threat Landscape

Email remains the primary initial access vector for advanced persistent threats, business email compromise (BEC), and automated cyber manipulation. Modern adversaries no longer rely solely on simple typographical errors or suspicious attachments. Instead, attacks have evolved into multi-modal social engineering campaigns:

  • Linguistic Manipulation & Synthetic Phrasing: Spear-phishing campaigns leverage urgency triggers, authority impersonation, and large language models (LLMs) to craft convincing, grammatically pristine text.
  • Sender Infrastructure Abuse: Attackers weaponize lookalike domain typography (typosquatting, IDN homographs) and exploit misconfigurations in domain authentication records (SPF, DKIM, and DMARC).
  • Steganographic Payload Delivery: Digital steganography embeds covert payloads inside arbitrary carrier images (PNG, JPEG, BMP), altering pixel values imperceptibly while preserving visual appearance. Conventional antivirus and secure email gateways cannot detect payloads hidden inside valid image structures.
  • The Explainability Deficit: Legacy security tools act as black boxes—they either silently quarantine messages or present generic warnings without explaining why an email is hazardous or how the recipient should respond.
Formal Overall Research Problem Statement

"Modern email-borne cyber attacks increasingly exploit distributed, multi-modal attack surfaces—combining social engineering text, domain impersonation, and concealed image steganography. Defenses in common practice evaluate these vectors in isolation and deliver opaque, binary verdicts without contextual explanations. Consequently, multi-channel attacks bypass perimeter filters, and recipient end users—lacking actionable reasoning—remain vulnerable to persistent manipulation."

Specific Research Objectives

Obj 1: Multi-Stage Threat Detection

Implement a sequential email threat detection pipeline combining DNS/reputation prefiltering, fine-tuned DistilBERT classification, and stylometric AI text profiling with hard score floors.

Obj 2: Deep Steganalysis with Grad-CAM

Develop an EfficientNet-B2 deep convolutional model for binary clean/stego classification, coupled with Gradient-weighted Class Activation Mapping (Grad-CAM) visual heatmaps.

Obj 3: Declarative Policy Defense

Construct an 18-rule declarative policy engine and severity arbitration layer that outputs calibrated five-level defense postures without unvalidated ML fusion.

Obj 4: Grounded Awareness & Profiling

Design an evidence-grounded awareness generation system and longitudinal vulnerability profiler tracking user security evolution across seven progression states.

Obj 5: Asynchronous Gateway Coordination

Architect a lightweight, asynchronous FastAPI gateway handling parallel worker dispatch, dependency isolation, and never-fail-open error handling.

Obj 6: Native Client Delivery & Triage

Deploy and validate a unified Mozilla Thunderbird MailExtension and SOC demonstration dashboard to evaluate end-to-end multi-modal triage across live attack scenarios.

System Architecture & Multi-Service Topology

MailSentra operates as a multi-service cluster on loopback (127.0.0.1:8000–8003). Because individual research components possess mutually exclusive library dependencies (e.g., conflicting PyTorch and scikit-learn pins), each service executes within its own isolated Python 3.11 virtual environment communicating strictly over HTTP.

The Never-Fail-Open Guarantee

If Component 01 or Component 03 encounters a timeout, corrupt file, or worker exception, the platform strictly reports an explicit partial status with detailed error fields. An unanalyzed attachment never defaults to safe or clean.
